# 📱 TADS Tech Store

Projeto final de e-commerce desenvolvido em React + Vite.

## 🚀 Como Rodar o Projeto
1. Instalar as dependências: npm install
2. Iniciar o projeto: npm run dev

## 🔐 Usuário e Senha de Teste
* **Usuário:** admin
* **Senha:** 1234

## 🛠️ Funcionalidades Implementadas
* Camada de Componentes (Cabecalho, Vitrine, ProdutoCard, Rodape, Layout)
* Filtros de busca por texto e categoria
* Consumo da API DummyJSON com tratamento de carregamento e erros
* Rotas com React Router (Home, Detalhes do Produto e Erro 404)
* Autenticação global com Context API e área protegida
